# 주차·이야기 지도·결산 Android 통합

이 문서는 Android 화면 통합의 출처, 이동 규칙과 서버 담당자에게 전달할 계약을 기록한다. 서버 구현·서버 계획 노트·마이그레이션 코드는 통합 범위에 포함하지 않는다. 로컬 지도 키 설정과 SDK 인증을 포함해 확인된 검증 범위는 아래에 기록하며 실제 서버 연결·지도 타일/마커 육안 검증·실차 검증과 구분한다.

여행 선택 화면을 구현하는 별도 채팅이 같은 `main` 작업 폴더에서 동시에 작성 중이다. 그 세션의 신규 데이터·ViewModel·화면·테스트와 목적지 확장 변경은 이 통합 커밋에서 제외한다. 공통 파일은 통합분의 고정 사본으로 검증하고 Git 인덱스에 그 내용만 반영하며, 작업 폴더의 선택 화면 변경을 덮어쓰지 않는다. 아래 검증은 두 원본 세션과 주차·종료 연결을 대상으로 하며 이후 여행 선택 세션의 최종 통합 검증과 구분한다.

## 화면 이동과 메모리 상태

- 홈 시작 → 여행 선택 연결 대기 화면 → 선택 완료 콜백의 실제 여행 ID → 주제 선택/주행 기록 → 도착과 P단 확인 → 주차 이야기 선택.
- 주차에서 목적지를 새로 설정하면 같은 여행 ID로 기록 흐름을 계속한다. `다음 목적지까지 기록 멈추기`가 켜졌으면 다음 도착 전까지 녹음하지 않고 도착 시 설정을 해제한다.
- 주차 여행 종료 → 본문 없는 `POST trips/{tripId}/finish` → HTTP 성공 확인(정상 응답 `204`) → 같은 여행의 결산 → 확인 → 홈. 비정상 HTTP 응답·시간 초과에는 녹음이 중단된 종료 대기 화면에서 재시도·홈 이동을 표시하며 결산으로 넘어가지 않는다. 자동으로 녹음을 재개하지 않는다.
- 이야기 지도 여행 선택 → 같은 여행 ID의 결산. 이 경로에서는 과거 여행 종료 요청을 보내지 않는다. 결산 뒤로가기 → 이야기 지도로 복귀하며 탭·정렬·선택 지역·목록 결과·스크롤 위치를 유지한다. 결산 확인 → 홈이며 보관함 메모리 상태를 정리한다.
- 앱을 다시 시작하면 홈에서 시작한다. 여행이나 지도 화면을 디스크에서 자동 복원하지 않는다. 현재 여행 ID, 주차 선택, 지도 표시 상태는 해당 탐색 흐름 안에서만 메모리에 유지한다.

실제 여행 선택·생성·이어가기 UI는 아직 구현되지 않았다. 연결 대기 화면은 내비게이션 경계를 제공하며 임의의 여행 ID나 서버에 없는 샘플 ID로 기록을 시작하지 않는다. 미래의 홈 구현은 새 여행을 서버에 생성하거나 실제 기존 여행을 선택한 뒤 선택 완료 콜백으로 ID를 넘긴다. 완료 여행을 이어갈 때 서버에서 어떤 상태로 다시 여는지도 홈·서버 계약으로 정해야 한다.

## 차량 UI 제한

이야기 지도와 결산의 목록·지도·상세 대화 조회와 조작은 `CarUxRestrictionsManager`의 현재 주행 중 UI 제한으로 허용 여부를 결정한다. 단순히 속도가 0이라는 이유로 허용하지 않는다. 차량 상태를 확인할 수 없거나 제한된 경우 안전 안내와 나가기/뒤로 조작만 제공한다. 특히 결산은 제한 중 이야기 ViewModel을 만들거나 조회하지 않고 이미 열려 있던 상세·말풍선도 숨긴다.

UI 탐색 허용과 애니메이션 허용은 별개다. 애니메이션은 시스템 애니메이션 설정·포그라운드·차량 제한을 반영하며, 애니메이션을 끄는 것만으로 운전 중 이야기 탐색을 허용하지 않는다. 주차 선택의 안전 판정은 도착 이벤트와 P단 상태를 사용한다.

## 공통 API와 정렬

[TRIP_API_CONTRACT.md](TRIP_API_CONTRACT.md)를 여행·주차·음성·종료의 공통 계약으로 삼는다. [ARCHIVE_API.md](ARCHIVE_API.md)는 완료 여행 목록과 지도 집계를, [TRIP_SUMMARY_INTEGRATION.md](TRIP_SUMMARY_INTEGRATION.md)는 결산 표시를 설명한다.

| 호출 | Android가 기대하는 결과 |
| --- | --- |
| `GET trips/{tripId}/stories` | 여행 전체 `stories`와 `savedStoryIds`. 최근 최초 등록순으로 표시 |
| `PUT trips/{tripId}/saved-stories` | 여행 전체 선택 ID를 `storyIds`로 교체. 정상 응답 `204` |
| `POST trips/{tripId}/finish` | 본문 없이 종료. 서버가 처리·저장·완료 상태를 확정한 뒤 정상 응답 `204` |
| `GET trips/{tripId}` | 구간 없는 `{tripId, stories, savedStoryIds}`. 저장된 이야기만 결산에 표시 |
| `GET trips?sort=latest` 또는 `oldest` | 사용자별 완료 여행 전체. 여행 날짜 최신/오래된순 |

주차의 최신순은 최초 등록순이며 제목·본문 수정이 순서를 바꾸지 않는다. 결산은 실제 `occurredAt`, 없으면 이야기별 `createdAt`을 기준으로 오름차순 표시하고 시간 없는 이야기는 뒤에 둔다. 같은 시간·시간 누락끼리는 서버 순서를 유지한다. 이야기 지도의 정렬은 여행 날짜 기준이다. `storyCount`는 최종 `savedStoryIds` 개수이며 저장하지 않은 대화를 더하지 않는다.

여행 종료 API는 Android Retrofit 호출만 추가한다. 서버는 이미 수신·수락한 음성의 AI 처리와 이야기 저장을 정리하고, 마지막 성공한 저장 집합·`savedCount = savedStoryIds.size`와 `finishedAt`·완료 상태를 일관되게 확정해야 한다. 목록의 `storyCount`는 같은 최종 저장 개수다. 이 상태가 조회에 반영되기 전에는 `204`를 보내지 않는다. 종료는 멱등적이며 응답 유실 후 같은 ID로 다시 요청해도 새 여행을 만들거나 완료 시각을 바꾸지 않는다. 화면에서 저장하지 않은 선택 변경을 종료가 대신 저장하지 않는다.

| --- | --- | --- |
| 여행 ID | 선택 완료 콜백으로 받은 ID를 REST/WSS에 그대로 전달 | 홈의 실제 여행 생성·선택·이어가기와 서버 여행 레지스트리 |

| 현재 위치 | SDK 현재 주소와 위경도. 미확인은 null | 서버가 이후 PCM에 이 문맥을 연결. 주소 미확인 시 이야기 지역명 대체 문구 |

| 방문 순서·최종 목적지 | 현재 `Destination`은 이름만 유지 | 홈·SDK 연동·서버가 목적지 전용 좌표와 방문 순서의 `destinations`를 공급 |

| 이야기 시간·본문·핵심 대화 | 생성하지 않고 서버 응답을 표시 | 서버가 실제 `occurredAt`·최초 `createdAt`·`content`·`conversationExcerpts`를 저장 |
| 여행 날짜·제목·완료 | 종료 ID만 전송. 앱은 날짜·완료 시각을 생성해 보내지 않음 | 서버가 여행 `date`의 기준 시점·시간대, 제목, 완료 상태·`finishedAt`과 최종 저장 개수를 확정 |

현재 차량 위치·마지막 이야기 좌표·임의의 도시 중심을 최종 목적지 좌표로 대신하지 않는다. 지도 계약이 요구하는 출발지·최종 목적지·시군 코드·날짜가 없으면 적절한 서버 계약과 공급 경로를 먼저 마련해야 한다. 데이터가 없는 것을 클라이언트 샘플이나 가상의 시간·대화로 채우지 않는다. 이 통합은 이러한 메타데이터를 서버에 자동 등록하는 기능을 완료했다고 주장하지 않는다.

## 빌드 설정과 샘플

- 공통 REST 주소는 `-Pdorolog.apiBaseUrl=https://host/api/`와 `BuildConfig.TRIP_API_BASE_URL` 한 선언만 사용한다. 호스트가 있는 HTTPS URL, 끝의 `/`, 사용자 정보·쿼리·fragment 금지 규칙을 공통 적용한다.
- 음성 연결은 별도 `-Pdorolog.voiceUrl=wss://host/conversation`와 `BuildConfig.DRIVING_VOICE_URL`을 사용한다. 비어 있으면 마이크/파형 확인만 가능하며 서버 음성 기능은 작동하지 않는다.
- 지도 키는 별도 `dorolog.kakaoMapNativeAppKey`와 `BuildConfig.KAKAO_MAP_NATIVE_APP_KEY`다. 사용자가 제공한 네이티브 앱 키는 Git에서 제외되는 `Android/local.properties`에 로컬 설정했다. `-P`를 포함한 Gradle 프로젝트 속성이 로컬 파일보다 우선하며 속성이 없을 때 로컬 파일을 사용한다. REST/WSS 주소와 혼용하지 않는다. 키 값은 문서·로그·커밋에 포함하지 않는다.
- 이야기 지도는 서버 주소 미설정 시 샘플임을 명시한 데이터만 표시한다. 운영 서버 오류를 샘플 성공으로 바꾸지 않는다. 주차·결산은 미설정/실패를 오류와 재시도로 표시하며 샘플 이야기로 대체하지 않는다.

실제 REST/WSS 주소, 인증 헤더와 사용자별 여행 접근 권한, 음성 제공자와 앞서 나열한 메타데이터 공급 경로는 아직 연결해야 한다. 사용자 인증이 필요한 서버에는 REST와 WSS 양쪽의 인증 전송 방식을 함께 연결해야 한다. 지도 키는 현재 개발 환경에 로컬 설정했으며 아래 SDK 인증 검증까지 확인했다. 이 문서는 서버 구현이나 배포 결과를 제공하지 않는다.

카카오 인증 테스트는 설정한 네이티브 앱 키로 SDK가 준비되는 것을 확인한다. 지도 타일이 최종 화면에 모두 렌더링되는지, 목적지 마커가 정확한지에 대한 수동 화면 확인 결과는 포함하지 않는다. 실제 REST/WSS 서버의 조회·저장·종료·음성 처리 전체 흐름도 이 인증 테스트의 검증 범위가 아니다.

통합 UI는 고정된 Android 사본의 APK로 Pleos 에뮬레이터에서 실행했다. 여행 ID 변경 시 결산 상태와 수집기를 함께 교체하고, 종료 요청 전 녹음·재생을 중단한다. 제한 화면의 Back 콜백은 디스패처로, 별도 테스트에서는 시스템 Back 입력으로 확인했다. 동시 작성 중인 여행 선택 기능과 실제 REST/WSS 서버의 전체 흐름, 지도 타일·마커 육안 확인과 실차 동작은 이 결과에 포함하지 않는다. 출발지·최종 목적지 좌표/시군·여행 날짜 등의 서버 메타데이터 공급도 별도 작업에서 확인해야 한다.
